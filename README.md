# 💰 Personal Budget Tracker

A simple and modern **personal finance web app** to track income, expenses, budgets, and visualize spending with interactive charts.

---

## 🚀 Features
- Add, view, and delete **transactions** (income & expenses).
- Set **budgets** per category with progress tracking.
- **Dashboard** summary (total income, expenses, balance, transaction count).
- **Charts** for category breakdowns and trends.
- Data persistence using **localStorage** (works offline).
- Clean, responsive **UI** for demo and presentation.

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Charts**: Chart.js
- **Storage**: localStorage (browser-based) can be extended to MongoDB
- **Backend **: Node.js + Express
